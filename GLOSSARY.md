# Skills

Quinn's personal Claude Code skills: the ticket flow (`/ticket`, `/work`, `/send`), the briefing, and the helpers around them.

## Language

**To-do**:
An open line in the vault's briefing notes, tagged with its project. Quinn writes one with `/note`, or it comes from a loose end that a ticket's session left behind.
_Avoid_: briefing note, project note, leftover

**Loose end**:
An open point a session reports when it stops: something still to check, decide or do that the session did not finish.
_Avoid_: leftover, open point

**Close**:
Ending a ticket without code, for example because it turned out already fixed or obsolete. The card goes to Done with the reason, and nothing ships.
_Avoid_: cancel, abandon, drop
